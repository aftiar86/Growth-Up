# Growth Up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a minimalist Android daily planner app in Kotlin with Jetpack Compose featuring an evening (H-1) planning phase, Day H checklist execution, compassionate task rollover/evaluation, local Room storage, notifications, and USB-connected device deployment.

**Architecture:** Clean MVVM architecture using Jetpack Compose (UI) -> StateFlow / ViewModel -> Repository Layer -> Room SQLite Database. Scheduled notifications managed via Android Notification & AlarmManager/WorkManager. Follows Ponytail principles (minimum code that works, no over-engineering) and UI/UX Pro Max guidelines (accessible pink minimalist palette, 48dp touch targets).

**Tech Stack:** Kotlin 1.9+, Android SDK (compileSdk 34, minSdk 26), Jetpack Compose, Material 3, Room Database, Coroutines & Flow, WorkManager / AlarmManager, Android Gradle Plugin, Git, Graphify, Mobile-MCP / ADB.

**Spec:** `docs/superpowers/specs/2026-11-22-growth-up-design.md`

## Global Constraints

- Platform: Android (minSdk 26, targetSdk 34).
- Language: 100% Kotlin with Jetpack Compose.
- Design: Minimalist Soft Pink aesthetic, high contrast (>= 4.5:1 for text), touch targets >= 48x48dp.
- Storage: 100% local persistence via Room, zero external server dependencies.
- Code style: Ponytail rules — smallest idiomatic change, zero boilerplate, DRY, YAGNI.
- Version Control: Git commits for every task, repository pushed to user's GitHub as "Growth Up".

## Review Focus

1. **Date Boundary Transition:** When the clock strikes midnight, tomorrow's plan must smoothly become today's active checklist without data corruption.
2. **Rollover Deduplication:** Moving an uncompleted task from today to tomorrow should update or duplicate it cleanly without creating infinite duplicate entries.
3. **Notification Permissions on Android 13+:** App must request `POST_NOTIFICATIONS` runtime permission gracefully so reminders trigger reliably.
4. **Empty State & First-Launch Experience:** When first installed with zero tasks, the app should warmly guide the user to add their first activity.
5. **Release Build Stability & R8 / ProGuard:** Release APK must build and launch cleanly without missing Room or Compose runtime classes.
